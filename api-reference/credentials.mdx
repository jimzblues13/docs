Learn how to get your  `private-key`.

## Authentication

Retrieve your `private-key`by:

1. Log in to the [Soca AI Platform](https://platform.soca.ai/).
2. Navigate to the **Developers** menu from the sidebar and select the **API Key** tab.
3. Click the **Create New API Key** button.
4. **Input a name** for your API key to help you identify it later.
5. Click **Generate**.
6. Once generated, copy your private-key. Store it securely—this key is required to authenticate API requests.

**Note:** Generate API Key is only available for **Business** and **Enterprise** subscription plans.
