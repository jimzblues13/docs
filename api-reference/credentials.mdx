Learn how to get your <code>private-key</code>.

## Authentication

Retrieve your <code>private-key</code> by:

1. Log in to the [Soca AI Platform](https://console.soca.ai/).
2. From the sidebar, go to the **API Keys** section.
3. Click the <code>Generate Key</code> button to create a new API key.
4. Once generated, copy your <code>private-key</code>. Store it securely—this key is required to authenticate API requests.
