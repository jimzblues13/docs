# Send Message Endpoint

This endpoint is used to send a prompt (command or question) to the message processing system and retrieve its response.

## Request

### Headers
| Key               | Value               | Description                     |
|-------------------|---------------------|---------------------------------|
| Content-Type      | application/json    | Indicates JSON format          |
| Authorization     | Bearer `<your_token>` | User authentication token      |

### Request Body
| Field      | Type   | Required | Description                               |
|------------|--------|----------|-------------------------------------------|
| session_id | string | Yes      | Conversation session ID to maintain context |
| sender     | string | Yes      | Who sends the message: `user` or `agent` |
| message    | string | Yes      | The actual message sent to the AI        |

## Response

### Status Code
**200** - `application/json`

### Response Body
| Field      | Type   | Description                                   |
|------------|--------|-----------------------------------------------|
| reply      | string | AI Agent's response                         |
| session_id | string | Same session ID as in the request           |
| timestamp  | string | Response timestamp in ISO 8601 format       |

## Example Usage
```json
POST /send_message

Headers:
{
  "Content-Type": "application/json",
  "Authorization": "Bearer <your_token>"
}

Body:
{
  "session_id": "abc123",
  "sender": "user",
  "message": "Hello!"
}

Response:
{
  "reply": "Hi there! How can I assist you?",
  "session_id": "abc123",
  "timestamp": "2025-04-08T12:34:56Z"
}
